# ROSHAYN

Small finds. Big energy.

An original responsive marketplace portfolio with 100 product concepts, real locally packaged photography, and a navy-and-lime identity.

## Features

- Five collections: Tech, Style, Home, Beauty, Everyday.
- Individual product descriptions, style details, and photo zoom.
- Full-catalog search, filters, sorting, favorites, and 24-item browsing batches.
- Shopping-bag quantities, an illustrative voucher, simulated checkout, and browser-local demo receipts.
- Desktop and mobile navigation and layouts.
- One-second featured-product carousel with the original pop transition, side arrows, and five compact navigation dots; all 100 products are accessible.
- Purple hover/focus feedback on category tiles and carousel arrows. Reduced-motion preferences disable carousel autoplay and movement; manual navigation remains available.

## Scope

This is a front-end portfolio demonstration. Photos, prices, discounts, and specifications are illustrative. It does not process real payments, orders, shipments, or seller transactions. Favorites, cart, voucher, and demo receipts are saved only in the visitor's browser.

## Website source

The public website is in site/. It is plain HTML, CSS, JavaScript, and local assets; there is no package installation or build dependency. ASSET-SOURCES.md records the photography and original brand assets.
